# FEAT-02-01

## 目的

实现 labelme 和内部数据集的相互转化。

## 代码路径

`convert/labelme.py`

## 详细设计

### FUNC-01: labelme -> 内部离线数据集

输入：
- 图片跟路径
- labelme 标注跟路径
- 类别名与 id 映射
- 加载数据格式：bbox、poly
- 是否将没有标注文件的照片加入数据集
  - True: 为该图片创建空的标注文件，并将图片和标注文件加入列表
  - False：跳过该图片，不将其加入列表

输出：
- 内部离线数据集

### FUNC-02: labelme -> 内部在线数据集

输入：
- 图片跟路径
- labelme 标注跟路径
- 类别名与 id 映射
- 加载数据格式：bbox、poly
- 是否将没有标注文件的照片加入数据集
  - True: 为该图片创建 shape 为 (0, ) 的空 Instances，并将图片和 Instances 加入列表
  - False：跳过该图片，不将其加入列表

### FUNC-03: 内部离线数据集 -> labelme

输入：
- 内部离线数据集
- 导出图片根路径
- 导出 labelme 标注根路径
- 导出数据格式：bbox、poly
- 导出路径模式
  - index: 按照序号将所有数据平铺放在导出根路径下
  - rel: 保持原始文件的相对路径结构放在导出根路径下
- 原始文件根路径：导出路径模式设为 rel 时生效，程序会按照它计算每个数据的相对路径

输出：无

### FUNC-04: 内部在线数据集 -> labelme

输入：
- 内部在线数据集
- 导出图片根路径
- 导出 labelme 标注根路径
- 导出数据格式：bbox、poly

输出：无

### FUNC-05: labelme -> 内部数据集，在线离线通用接口

输入：
- 图片跟路径
- labelme 标注跟路径
- 类别名与 id 映射
- 加载数据格式：bbox、poly
- 内部数据集模式：online、offline
- 是否将没有标注文件的照片加入数据集

输出：内部离线或在线数据集

### FUNC-06: 内部数据集 -> labelme，在线离线通用接口

输入：
- 内部离线或在线数据集
- 导出图片根路径
- 导出 labelme 标注根路径
- 导出数据格式：bbox、poly
- 数据集模式：online、offline
- 导出路径模式，仅对离线数据集生效
  - index: 按照序号将所有数据平铺放在导出根路径下
  - rel: 保持原始文件的相对路径结构放在导出根路径下
- 原始文件根路径：仅对离线数据即生效，导出路径模式设为 rel 时生效，程序会按照它计算每个数据的相对路径

输出：无
