# FEAT-02-01

## 目的

实现 labelme 和内部数据集的相互转化。

## 代码路径

`convert/labelme.py`

## 函数设计

### FUNC-01: labelme -> 内部数据集

输入：

- 图片跟路径、labelme 标注跟路径
- 类别名与 id 映射
- 加载数据格式：bbox、poly
- 加载模式：offline、online
- 是否将没有标注文件的照片加入数据集
  - True: 将标注以 shape 为 (0, ) 的 Instances 加入数据集
  - False：不将该标注和对应图片加入数据集

输出：

- 内部在线数据集、或内部离线数据集

### FUNC-02: 内部数据集 -> labelme

输入：

- 内部数据集
- 内部数据集模式：offline、online
- 导出图片根路径、导出 labelme 标注根路径
- 导出数据格式：bbox、poly
- 是否为没有标注的图片导出空白标注文件

输出：

- 无

逻辑：

- 若内部数据集模式为 offline，单纯进行文件拷贝
- 若内部数据集模式为 online，将存储的标注实体转化为 labelme 标注文件
