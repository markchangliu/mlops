# FEAT-01-01 数据契约

## 目的

用 `TypeAlias`、`TypedDict` 为以下数据定义类型和格式：

- bboxes, masks, polygons, rles
- instances
- 数据集
- evaluation result

## 代码位置

`core/schema.py`

## 内部 Instances

一个融合了 confs、cat_ids、bboxes、polys 的结构体，可以对它们同时进行索引、切片等操作

## 内部数据集

内部数据集分成两个子类：

- 离线数据集：存储图片路径、标注文件路径（标注文件为 labelme）
- 在线数据集：存储图片路径、标注实体（bbox、poly）
