# FEAT-01-01 数据契约

## 目的

* 为所需数据编写格式定义，方便查阅和实现代码提示。
* 为第三方标注之间的转化搭建一个桥接。
* 为内部模块约定一个统一的数据格式规范。

## 设计原则

### 包含范围

* 检测框和分割掩码标注 (shapes)
* 检测或分割实例 (instances)
* 数据集 (dataset)
* 评估结果 (evaluation result)

### 定义方式

* 类型定义的命名格式统一为 XXXType
* 类型定义只包含 type annotation，不包含任何运算代码

### 代码位置

`core/schema.py`

## 详细设计

### 检测框和分割掩码标注 (shapes)

bboxes、masks 等结构一致的数据用 NDArray 表示。

polys、rles 等结构不一致的数据用 list、dict 表示。

### 检测或分割实例 (instances)

检测或分割实例数据用 dict 表示，它包含 keys：cat_ids、confs、bboxes、polys。

### 数据集（dataset）

数据集分成两个子类：
* 离线数据集：存储图片路径、标注文件路径（labelme 标注文件）
* 在线数据集：存储图片路径、检测或分割实例（instances）

两种数据集均用 dict 表示。

### 评估结果（evaluation result）

评测结果分为两个子类：
* 离线评测结果：存储图片路径、GT 标注文件路径、Pred 标注文件路径
* 在线评测结果：存储图片路径、GT 检测或分割实例、Pred 检测或分割实例

离线单图评测结果用 dict 表示，包含以下 key:
- 图片路径
- GT 标注文件路径
- Pred 标注文件路径
- gt_pred_id_dict：每个 GT 对应的 Pred id
- pred_gt_id_dict：每个 Pred 对应的 GT id
- tp_flags：每一个 Pred 是否为 TP
- fn_flags：每一个 GT 是否为 FN
- mAP：这张图片的 mAP
- precision: 这张图片的 precision
- recall：这张图片的 recall
- tp_avg_iou：所有 TP 的平均 iou

在线单图评测结果用 dict 表示，包含以下 key：
- 图片路径
- GT 检测分割实例
- Pred 检测分割实例
- gt_pred_id_dict：每个 GT 对应的 Pred id
- pred_gt_id_dict：每个 Pred 对应的 GT id
- tp_flags：每一个 Pred 是否为 TP
- fn_flags：每一个 GT 是否为 FN
- mAP：这张图片的 mAP
- precision: 这张图片的 precision
- recall：这张图片的 recall
- tp_avg_iou：所有 TP 的平均 iou

数据集评测结果用 dict 表示，包含以下 key：
- 在线或离线单图评测结果列表
- num_preds：所有的 Pred 数量
- num_tps：所有的 TP 数量
- num_gts：所有的 GT 数量
- num_fns：所有的 FN 数量
- mAP_insts：以实例为单位的全局 mAP
- mAP_imgs：以图片为单位的全局 mAP
- precision_insts：以实例为单位的全局 precision
- precision_imgs：以图片为单位的全局 precision
- recall_insts：以实例为单位的全局 recall
- recall_imgs：以图片为单位的全局 recall
- tp_avg_iou：所有 TP 的平均 iou
