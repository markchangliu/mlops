# Design-01

## 客户需求

* Labelme、COCO、YOLO 三种检测和分割数据集之间的转换
* 通过 mAP、precision、recall 三个指标评估模型的性能
* 单个标注以及整个数据集标注的可视化
* 测试集 TP、FP、FN 的可视化

## 设计原则

### 数据定义和运算分离

数据定义代码是描述一种数据形态、格式等属性的描述性代码，只包含 type annotation 相关的语言。

运算代码则是“做某件事情”的过程指导性代码。

这两种代码要解耦分开放，所有的数据定义代码统一放在一起，运算代码则根据架构的划分放在各自的模块中。

### 函数为主，类为辅

运算代码的逻辑以函数实现，类仅用于协助架构设计、提供 API、以及规范内部接口。

类代码保持简介，类内部的方法尽量通过调用对应的函数实现。
